# 바람지문 (WindPrint) — 부산 에코델타시티 악취 역추적 디지털트윈

2026 국가시범도시 AI 아이디어·기술 공모전 / Track 01 국민 AI 아이디어
분야 4. 도시데이터·디지털트윈 · 4-4 AI 기반 소각시설 유해물질 확산 예측 및 대기환경 영향 관리 서비스

시민의 악취 신고 한 건에서 **바람을 거슬러** 원인 배출원을 찾는 아이디어의 두 가지 시제품입니다.
둘 다 외부 CDN·서버 없이 **단일 HTML 파일**로 동작합니다(오프라인 실행, 콘솔 오류 0건).

| 화면 | 파일 | 내용 |
| --- | --- | --- |
| **3D 디지털트윈** | [`index.html`](index.html) · <https://jackdinealkim.github.io/windprint-3d/> | 에코델타시티·생곡산단·명지 일대. 사건 3종(야간 복합악취·새벽 정체·오후 연소), 신고 → 사건화 → 역추적 → 악취 지문 → 기여도 → 도착 알림 → 시설 감축 운전. 시민/관제 모드. Three.js r158 |
| **역추적 엔진 분해도** | [`anatomy.html`](anatomy.html) · <https://jackdinealkim.github.io/windprint-3d/anatomy.html> | 같은 계산 구조를 손으로 만질 수 있는 계측기로 그린 아이소메트릭 분해도. 수신 혼(신고) · 풍향 날개/풍속 컵(기상) · 분배 매니폴드와 로타미터 3본(기여 확률) · 스로틀 밸브(감축 운전) · 환산 농도계 · IoT 센서 3노드(삼각측량). 호버·분해·슬라이더로 실시간 수치가 바뀝니다 |

## 조작

- 3D: 드래그 회전 · 휠 확대 · `냄새 신고해 보기` → 지도 클릭 · `바람 거꾸로 추적` · `도착 예측 알림` · `시설 감축 운전 비교`
- 분해도: `부품 분해` · 풍향/풍속/감축 슬라이더 · 부품에 마우스를 올리면 설명 · ←/→ 풍향, Space 분해

## 데이터·한계

- 통계·지명은 공개 보도자료(부산일보 2026.10.18, 연합뉴스 2026.10.30, 뉴시스 2026.11.10, K-water 사업개요)를 근거로 했습니다.
- 지형·건물·입자는 축척 시뮬레이션이며 실제 측량·측정값이 아닙니다.
- 기여 확률과 환산 농도는 풍향·풍속·거리·악취 지문 일치도를 조합한 시제품 계산식의 결과입니다(역궤적·역확산 모델의 단순화).
  분해도의 세 로타미터 부자와 농도계 바늘은 이 계산식과 같은 모델에서 나옵니다.
